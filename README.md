# **Codificador**

## **Tecnologias Utilizadas**
- **HTML5**: Para estruturar a interface da aplicação.
- **CSS3**: Para estilizar a página e criar uma experiência visual agradável.
- **JavaScript**: Para implementar a lógica de criptografia, descriptografia e interações do usuário.

---

## **Intuito do Codificador**
O objetivo do "Codificador" é proporcionar uma forma prática e intuitiva de proteger mensagens ao substituí-las por um código simples e reversível. A aplicação também serve como um aprendizado prático para explorar conceitos de programação, como manipulação de strings, interatividade com o DOM e lógica de criptografia básica.

---

## **Descrição**
O "Codificador" é uma aplicação web que permite **criptografar** e **descriptografar** textos com facilidade. Ele substitui as vogais por códigos específicos, tornando as mensagens seguras para compartilhamento.

## **Funcionalidades**
- **Criptografar texto**: Converte as vogais do texto em códigos predefinidos.
- **Descriptografar texto**: Restaura o texto criptografado ao seu formato original.
- **Copiar texto**: Permite copiar o resultado para a área de transferência com um clique.

---

## **Como Usar**
1. **Digite o texto** na caixa de entrada disponível na interface.
2. Clique no botão **"Criptografar"** para converter o texto em sua versão codificada.
3. Clique no botão **"Descriptografar"** para decodificar o texto e restaurar o conteúdo original.
4. Para copiar o resultado, clique no botão **"Copiar"**.

---
